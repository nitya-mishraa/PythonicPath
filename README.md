## 📌 About

This repo is where my LeetCode journey lives — every problem I solve, organized and pushed automatically, no manual copy-pasting involved.

It's not a curated highlight reel. It's the real record: the rough first attempts, the "wait, there's a better way" rewrites, and everything in between. A path, not a portfolio.

---

## ⚙️ How it stays updated

Solutions land here automatically via **LeetSync** — the moment a submission is accepted on LeetCode, it gets pushed straight into this repo. No dashboards to babysit, no "I'll upload it later."
